Como Navegar e Usar o Zoom

📱 No Celular / Tablet (Touch)

  • Movimento de Pinça: Abra ou feche 2 dedos sobre a imagem para ampliar ou diminuir até 5x.
  • Arrastar ampliado: Quando com zoom, use um dedo para navegar em qualquer canto do infográfico.
  • Duplo Toque: Toque duas vezes rápido na imagem para dar zoom instantâneo de 2.5x naquele ponto.
  • Trocar de Slide: Quando em tamanho normal (1x), deslize o dedo para os lados (swipe).

💻 No Computador (Teclado e Mouse)

  • ← / → : Slide anterior / próximo
  • + / - : Aumentar / diminuir zoom
  • 0 ou Esc : Resetar zoom / Fechar janelas
  • F : Alternar Tela Cheia
  • Espaço : Iniciar / pausar apresentação automática
  • G : Abrir grade com todos os infográficos
  • Scroll do Mouse: Role a rodinha sobre a imagem para zoom suave no ponteiro.
